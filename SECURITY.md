# Безопасность Zoom Meeting Agent

Продукт предназначен для записи встреч, разрешённых пользователю и организатору.
Запись начинается по явной команде; LLM выключена по умолчанию. Открытый код и
прошедшие тесты не гарантируют отсутствие всех уязвимостей.

## Границы доступа

- HTTP ядра доступен только на loopback и требует отдельный токен встречи.
- MCP работает через локальный stdio, принимает ID профиля/сессии, не произвольные
  пути, команды, пароли или PID. Поддерживаются две активные управляемые записи.
- MCP-файлы открываются через POSIX directory handles с запретом symlink.
  На Windows эти операции отклоняются; отдельный CLI остаётся доступен.
- Это не защита от другого процесса с правами того же пользователя ОС или root.
  Записи должны храниться в личном каталоге, при необходимости на зашифрованном диске.

## Секреты и данные

Ссылки с паролями, API-ключи и SDK credentials вводятся через локальный терминал;
вход в Zoom проходит в видимом браузере. `.env`, `storage_state.json`, `meetings/`,
`sessions/` и `runs/` не публикуются. Генератор архива отвергает эти файлы даже
при случайном добавлении в Git.

Zoom передаёт звук через свою сеть. Распознавание работает на компьютере;
Whisper заранее загружается отдельной командой. При выборе LLM текст передаётся
Claude/OpenAI/DeepSeek. CLI может добавлять служебные инструкции окружения.
Чтение текста инструментом MCP передаёт его AI-клиенту независимо от настройки
встроенной LLM. Границы модели и известные ограничения описаны в README.

DeepSeek вызывается без инструментов, только по фиксированному HTTPS-адресу.
Редиректы, незавершённый ответ и tool calls отвергаются. Отдельный процесс
ограничивает общее время запроса; пароль/ключ не попадает в argv. Автоповторов нет.

## Остановка и восстановление

Штатная остановка сохраняет последний аудиофрагмент и обрабатывает очередь.
На Linux проверена остановка принадлежащего программе дерева процессов с
проверкой идентичности процессов. SIGKILL, перезагрузка и потеря питания не дают
гарантии сохранения хвоста; старый PID не используется для убийства нового процесса.

Разрыв MCP-соединения не останавливает запись. Worker работает до срока профиля
или stop_session. После штатного завершения его временные копии cookie/пароля
удаляются; после аварии они могут остаться в закрытом runs-каталоге. Исходный
профиль, cookie и записи хранятся до отдельного решения пользователя об удалении.

SDK устанавливается с ограниченной распаковкой и сохранением прежних файлов.
Ошибка установки восстанавливает прежний static; копии остаются в .sdk-backups.
Это не проверка безопасности всего кода зависимостей и не гарантия совместимости
любой версии SDK. Результаты локальных проверок: [VERIFICATION](zoom-meeting-agent/VERIFICATION.md).
