# Изменения

## 2026-10-26 — исправления после аудита, версия для Codex

- У каждой встречи собственные порт, токен и каталог. Ответ отправляется только в явно выбранную сессию.
- Локальный HTTP требует авторизацию, проверяет адрес и источник запроса, ограничивает размеры и число соединений. Имена аудиофрагментов не позволяют выйти из каталога или перезаписать файл.
- Подключение подтверждается состоянием встречи; запись отслеживает звук, процесс распознавания и его heartbeat. Ошибки сохраняются в состоянии сессии и не превращаются в успешный протокол.
- Протокол обрабатывает весь сохранённый текст частями, сохраняет цитаты и происхождение фактов. Успешные части кешируются. Превышение лимита или ошибка дают явный незавершённый результат.
- LLM выключена по умолчанию. Claude и Codex получают текст только после явного выбора; возможности исполнения команд и доступа к рабочим инструментам отключены.
- Добавлен отдельный запуск `zoom-meeting-agent-codex/` с собственными настройками и данными. Общее ядро входит в архив; Claude для этой версии не нужен.
- Добавлены диагностика установки, автоматические проверки, 16 синтетических смысловых сценариев и сборка архива без записей и учётных данных.
- Полный протокол сохраняется локально. Автоматическая доставка в Telegram отключена, старые `TELEGRAM_*` настройки игнорируются.

Это версия для проверки. Протокол остаётся черновиком: цитаты не доказывают правильность смысла, а поздние исправления не сводятся автоматически в окончательный список поручений. Живой Zoom, Claude, Windows и macOS требуют отдельного прогона. Измерения и границы проверки описаны в [VERIFICATION.md](zoom-meeting-agent/VERIFICATION.md).
