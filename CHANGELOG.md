# Изменения

## 2026-10-28: личный аккаунт и отдельный аккаунт ассистента

- Добавлены независимые профили `personal` и `assistant`, явный гостевой режим
  и совместимость с прежним одиночным входом. Выбор сохраняется для встречи.
- CLI и MCP используют выбранный профиль; отсутствие входа не вызывает
  подстановку другого аккаунта или гостя. MCP удаляет только свои копии входа.
- Локальный вход, обновление с приватной резервной копией и явный импорт
  старого входа не раскрывают cookie. Регистрацию нового аккаунта делает человек.
- Обновлён общий скилл для Claude Code, Codex и Cursor. Оба живых авторизованных
  сценария ещё требуют проверки; наличие профиля не объявляется успешной записью.

## 2026-10-28: границы гостевого и авторизованного прогона

- Уточнено, что отказ Zoom получен гостем из изолированного каталога без
  сохранённого входа. Авторизованный путь последнего кода не повторён.
- Отказ гостю не доказывает отказ всем режимам, изменение политики за несколько
  дней или причинную связь с Basic. Сравнение этих условий ранее было неполным.
- Запуск явно сообщает, передан ли сохранённый вход браузера. Событие
  `browser_auth` не содержит cookie и не утверждает, что вход действителен.

## 2026-10-28: настоящий отказ Zoom в доступе боту

- Живая попытка Web-входа с приглашением встречи получила явный запрет
  автоматических ботов. Вход не подтверждён, записи и расшифровки нет.
- Состояние `zoom_automation_blocked` отделено от обычного запроса входа
  аккаунтом. Инструкции требуют остановить попытки при таком отказе.
- README, первый запуск, Codex edition и llms.txt отражают неуспех живого
  сценария. RTMS не реализован; завершение интеграции не заявляется.

## 2026-10-28: код доступа в Web-превью

- Позднее окно выбора микрофона и камеры обрабатывается и как ссылка внутри
  модального окна. Неизвестные перекрывающие окна не закрываются автоматически.
- Неактивная кнопка входа ожидает следующей проверки состояния. Сообщение
  Zoom `Incorrect Password` распознаётся как отклонённый код доступа.
- При видимом поле кода доступа Web-слушатель явно сообщает, что нужен
  локально настроенный код. Вместо этого раньше мог возникать тайм-аут.
- Код из локального профиля заполняется и в форме превью. Имя гостя
  заполняется по полю актуального интерфейса, скрытые кнопки пропускаются.
- Отклонённый код не отправляется повторно автоматически.
- Восемь проверок с настоящим локальным Chromium подтверждают обработку формы;
  они не подтверждают вход в настоящую Zoom-встречу.

## 2026-10-28: продолжение проверок по аудиту Кирилла Эфроса

- Завершён четырёхчасовой локальный прогон исторического снимка: 722/722
  сохранённых фрагмента обработаны, 35/49 контрольных слов распознаны точно,
  финальная фраза найдена. Позднее исправление времени оценки маркеров основано
  на записанных событиях браузера; исходная оценка сохранена.
- Опубликованы настоящий текстовый вызов Claude и параллельные проверки:
  дедлайн на двух ядрах не достигнут; на четырёх обе записи завершились.
  Пропущенное в короткой записи поручение остаётся неуспехом распознавания.
- Исправлено зависание при настоящем Ctrl+C: INT/TERM выставляют флаг, запись
  сохраняет хвост и завершает STT после возврата браузерного вызова.
- На Linux дочерние процессы записи завершаются при смерти родителя; явно
  отделённый MCP worker продолжает запись после отключения клиента.
- На последнем снимке прошли 243 теста без пропусков в CI, установка на трёх ОС
  и локальные проверки сигналов, восстановления STT и обычного завершения.
  Исторические неуспехи сохранены рядом с повторными результатами.

- Загрузка настоящих SDK в браузере выявила отсутствующий ReactRedux при откате
  и неустановленные UI-ресурсы. Установщик теперь копирует весь UI, а doctor
  проверяет стили; загрузка SDK 6.5/6.10/6.5 повторно прошла без ошибок.
- Опубликован неуспех качества цепочки со звуком: ошибки STT в проектах,
  двух сроках и одном действии перешли в протокол. Техническое завершение
  не выдаётся за смысловую приёмку. Альтернативное декодирование не дало
  устойчивого улучшения и не включено по умолчанию.
- SDK-режим помечен экспериментальным с учётом текущих указаний Zoom о Web
  Meeting SDK и ботах; RTMS в продукте отсутствует.

- Запросы управления отклоняют неизвестные поля до изменения очереди или состояния.
- Таймаут ffmpeg завершает принадлежащее ему дерево процессов. При остановке записи
  прерванный аудиофрагмент сохраняется для финальной обработки.
- Сигнал остановки сначала получает управляющий процесс, затем его декодеры.
- Вывод статуса в ASCII-терминале больше не превращает сохранённый результат в ошибку.
- Уточнена инструкция модели: отложенное предложение должно остаться предложением,
  даже если поручение ещё не принято.
- Добавлен прогон установки из одного исходного ZIP на Linux, Windows и macOS.
  Он прошёл на Ubuntu 24, macOS 26.6.2 ARM64 и Windows Server 2025. Исправлены
  передача путей с пробелами на Windows и пустой аудиохвост при ранней остановке
  на macOS. Windows 11 и живой Zoom не объявляются проверенными.
- MCP передаёт управляемой записи путь к установленному Chromium, сохраняя
  исключение ключей провайдеров и Telegram из окружения дочернего процесса.
- Опубликованы результаты 237 локальных тестов, реального Whisper на 30 минутах
  синтетики, 50 генераций Codex, проверки HTTP, ошибок процессов и лимита ответов.
  [Матрица 50 ID и доказательства](zoom-meeting-agent/VERIFICATION.md) различают
  выполненные процедуры, частичное покрытие и оставшиеся условия.
- Спасибо Кириллу Эфросу ([@kep95](https://t.me/kep95)), автору исходного аудита
  безопасности, воспроизводимых проверок и набора из 50 сценариев.

## 2026-10-27: скилл, установка и MCP

- Скилл для первого запуска в Claude Code, Codex и Cursor: установка окружения,
  аккаунты, тестовая запись, повтор протокола и диагностика. Скилл устанавливается
  отдельно от настроек клиента, повторная установка сохраняет прежние правки.
- Установщик продолжает прерванные шаги, проверяет реальные зависимости и загрузку
  модели. Whisper скачивается явно; во время записи используется локальный кеш.
- Ссылка встречи, пароль, SDK credentials и DeepSeek-ключ вводятся локально.
  Прямой DeepSeek API получает только текст, без инструментов, с общим deadline.
- MCP на stdio: семь инструментов, отдельные управляемые записи, остановка после
  переподключения и ограниченное чтение. Лимит двух активных записей защищён
  межпроцессной блокировкой; файловые операции пока требуют POSIX.
- Исправлена остановка дочерних процессов. SDK распаковывается с ограничениями;
  предыдущая установка сохраняется, ошибки переключения откатываются.
- Поздний фрагмент речи больше не завершает текстового агента и не повторяет
  уже обработанные вопросы. Протокол принимает только полный фрагмент источника
  в цитате. Проверка не подтверждает смысл и связи между разными фрагментами.
- Время начала аудиофрагмента оценивается по его фактической длительности;
  короткий последний фрагмент больше не считается двадцатисекундным.
- Публичные инструкции различают локальные проверки, реальные встречи и качество
  моделей. Windows/macOS, живой Zoom и длинные прогоны не объявляются проверенными.

## 2026-10-26: дополнительные исправления по внешнему набору проверок

- Очередь SDK сохраняет сообщения до подтверждения доставки. Браузер резервирует сообщение перед отправкой; потеря ACK не вызывает повторную отправку. Ошибка и неопределённый результат остаются видимыми в локальном журнале.
- Повреждённые события и незавершённые UTF-8/JSONL-записи не мешают обработке следующего вопроса. Обычное упоминание слова «бот» больше не запускает ответ. Добавлены пределы попыток ответа за минуту и за запуск.
- Сырые ошибки SDK не сохраняются вместе с параметрами подключения. Пароль встречи читается из локального файла через `--password-file`; старый `--pwd` отклоняется. Типовой файл пароля исключён из Git и архивов.
- STT фиксирует отдельные записи обработанных фрагментов и восстанавливает расшифровку после прерванного сохранения. При свободном месте менее 64 МиБ запись завершается с явной ошибкой.
- Добавлены проверки HTTP, Chromium, восстановления после сбоя и ограничений вызовов. Полное прохождение внешних 50 стендовых сценариев не заявляется.

## 2026-10-26, исправления после аудита, версия для Codex

- У каждой встречи собственные порт, токен и каталог. Ответ отправляется только в явно выбранную сессию.
- Локальный HTTP требует авторизацию, проверяет адрес и источник запроса, ограничивает размеры и число соединений. Имена аудиофрагментов не позволяют выйти из каталога или перезаписать файл.
- Подключение подтверждается состоянием встречи; запись отслеживает звук, процесс распознавания и его heartbeat. Ошибки сохраняются в состоянии сессии и не превращаются в успешный протокол.
- Протокол обрабатывает весь сохранённый текст частями, сохраняет цитаты и происхождение фактов. Успешные части кешируются. Превышение лимита или ошибка дают явный незавершённый результат.
- LLM выключена по умолчанию. Claude и Codex получают текст только после явного выбора; возможности исполнения команд и доступа к рабочим инструментам отключены.
- Добавлен отдельный запуск `zoom-meeting-agent-codex/` с собственными настройками и данными. Общее ядро входит в архив; Claude для этой версии не нужен.
- Добавлены диагностика установки, автоматические проверки, 16 синтетических смысловых сценариев и сборка архива без записей и учётных данных.
- Полный протокол сохраняется локально. Автоматическая доставка в Telegram отключена, старые `TELEGRAM_*` настройки игнорируются.

Это версия для проверки. Протокол остаётся черновиком: цитаты не доказывают правильность смысла, а поздние исправления не сводятся автоматически в окончательный список поручений. Живой Zoom, Claude, Windows и macOS требуют отдельного прогона. Измерения и границы проверки описаны в [VERIFICATION.md](zoom-meeting-agent/VERIFICATION.md).
