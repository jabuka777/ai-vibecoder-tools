# AI Vibecoder Tools — полезные инструменты, собранные вайбкодингом с ИИ-агентами

Открытая коллекция небольших рабочих инструментов, которые я собираю вместе с
ИИ-агентами (Claude Code, Codex): от постановки задачи до работающего кода за
минуты или часы, а не недели. Каждый инструмент проверен в бою. В README описано,
**что он делает, сколько занял и где грабли**.

> **Вайбкодинг** — разработка, в которой человек ставит задачу и принимает
> решения, а код, проверку и рутину делает ИИ-агент. Здесь лежат результаты, без
> презентаций.

## Инструменты

| Инструмент | Что делает | Сколько заняло | Стек |
|---|---|---|---|
| [**Zoom Meeting Agent**](zoom-meeting-agent/) | ИИ-агент заходит в Zoom-созвон, расшифровывает речь локально (whisper), отвечает в чате через Claude, присылает выжимку встречи. Может тихо слушать любую встречу по ссылке через веб-клиент | ~20 минут до первого входа, ~1 час до слушателя чужих встреч | Python, Playwright, Zoom Meeting SDK Web, faster-whisper, Claude Code |

Новые инструменты добавляются по мере того, как появляются и проходят проверку.

## Принципы

- **Безопасно по умолчанию.** Никаких ключей в коде: всё через `.env` (есть
  `.env.example`). Звук и данные по возможности обрабатываются локально.
- **Честно про ограничения.** Если платформа что-то запрещает (например, Zoom с
  марта 2026 не пускает SDK-ботов в чужие встречи), это написано в README вместе с
  обходом, если он есть.
- **Повторяемо.** Установка в несколько команд, проверка без людей, где это
  возможно.

## Частые вопросы

**Можно ли подключить ИИ-агента к Zoom-встрече?** Да. Во встречи своего аккаунта —
через Meeting SDK (`bot.py`). В любую встречу по ссылке — через обычный веб-клиент
Zoom (`webjoin.py`): агент заходит как участник без микрофона и камеры. Подробности —
в [zoom-meeting-agent](zoom-meeting-agent/).

**Почему Zoom-бот на SDK не заходит в чужую встречу и показывает «Sign in»?** С
02.03.2026 Zoom требует для SDK-ботов OBF-токен: в чужие встречи бот попадает только
вместе с человеком, который авторизовал приложение и уже сидит во встрече.

**Уходит ли звук встречи в облако?** Нет: расшифровка идёт локально через
faster-whisper. В LLM уходит только текст — для ответа в чате и для выжимки.

*English summary:* open collection of small, battle-tested tools built by vibecoding
with AI agents (Claude Code). First tool: **Zoom Meeting Agent**. It joins Zoom calls,
transcribes locally with faster-whisper, answers in meeting chat via Claude and posts
a meeting summary. It can also silently join any meeting through the Zoom web client,
which works around the March 2026 OBF restriction for Meeting SDK bots in external
meetings. Author: Evgeny Ambrosyuk ([@Eugene_Amb](https://t.me/Eugene_Amb)).
