# Открытые инструменты Ябуки

[Ябука](https://jabuka.ru), сервис Apple в Москве. Чиним и продаём iPhone, MacBook, iMac, iPad, Apple Watch и AirPods. Каждый день к нам приходят с одними и теми же проблемами: данные застряли в iCloud, телефон не делает резервную копию, после созвона никто не помнит, о чём договорились. Для себя мы написали инструменты, которые эти проблемы закрывают, и выкладываем их бесплатно под лицензией MIT.

| Инструмент | Что решает | Статус |
|---|---|---|
| [Zoom Meeting Agent](zoom-meeting-agent/) | Расшифровка Zoom-встречи на вашем компьютере и черновик протокола: кто что обещал и к какому сроку | установка проверена в CI на Linux/macOS/Windows Server; живой Zoom требует прогона |
| [Zoom Meeting Agent · Codex](zoom-meeting-agent-codex/) | То же через Codex вместо Claude | отдельный запуск на общем ядре |
| Перенос данных из iCloud | Выгрузка контактов, календарей, заметок, напоминаний, iCloud Drive и фото на свой диск, Яндекс Диск, Google Диск или NAS | готовится к публикации |

## Вопросы и ответы

### Как забрать фото и данные из iCloud, если iCloud+ в России не оплатить?

С 1 апреля 2026 года Apple ID нельзя пополнить со счёта мобильного телефона. Когда подписка iCloud+ заканчивается, остаётся бесплатный объём 5 ГБ, и резервная копия iPhone перестаёт создаваться. Данные из iCloud при этом не пропадают сразу, но новые фото туда уже не попадут.

Что делать: выгрузить всё из iCloud в другое место, причём в два места сразу. Одна копия в одном облаке ещё не резервная копия. В октябре 2026 года Яндекс Диск несколько дней работал с ограничениями после атаки на дата-центры. Надёжная схема: облако плюс внешний диск или два разных облака.

Наш инструмент для этого готовится к публикации. Если нужно сейчас и руками не хочется, перенос данных со старого iPhone или Mac на новое устройство делают в сервисе [Ябука](https://jabuka.ru).

### Можно ли расшифровать Zoom-созвон без отправки записи в облако?

Да. [Zoom Meeting Agent](zoom-meeting-agent/) заходит во встречу как участник через Chromium, сохраняет звук на вашем компьютере и распознаёт речь локально моделью faster-whisper. Отдельный облачный сервис распознавания не нужен. Интернет нужен Zoom и первоначальной установке пакетов, браузера и модели. Само распознавание использует локальный кеш.

### Как получить протокол встречи с задачами и сроками?

После встречи агент собирает черновик протокола: решения, поручения, исполнителей, сроки, отмены. К каждому пункту приложена цитата из расшифровки, чтобы его можно было проверить. Для этого текст встречи передаётся выбранной модели (`--llm claude`, `--llm codex` или `--llm deepseek`). По умолчанию встроенная LLM выключена, и текст ей не отправляется. Чтение расшифровки через MCP передаёт её AI-клиенту.

### Может ли ИИ-агент отвечать в чате Zoom во время встречи?

Да, в SDK-режиме. В веб-режиме агент только слушает. Войти во встречу агент может, если это разрешают настройки встречи и организатор: ограничения Zoom он не обходит.

## Что происходит с данными

Zoom передаёт звук через свою сеть. Chromium сохраняет аудиофрагменты на вашем компьютере, faster-whisper распознаёт их локально. Команда установки заранее скачивает модель Whisper; запись использует уже проверенный локальный кеш.

Языковая модель по умолчанию выключена. Флаг `--llm claude`, `--llm codex` или `--llm deepseek` разрешает передать текст речи и чата выбранному провайдеру. MCP читает результат только по запросу пользователя; этот текст попадёт в контекст его AI-клиента.

## Что проверено

В репозитории есть тесты изоляции сессий, HTTP-доступа, ошибок звука, полноты обработки текста и запуска модели без доступа к рабочим инструментам. Отдельные 16 синтетических сценариев проверяют исполнителя, срок, проект, предложения, отмены и ошибки извлечения.

Офлайн-тесты не доказывают качество ответа модели. Протокол остаётся черновиком с цитатами, его проверяет человек. Отмены и исправления сохраняются рядом с прежними задачами; окончательный список действующих поручений автоматически не определяется.

28.10.2026 прошли 237 локальных тестов и CI установки из ZIP на Ubuntu,
macOS ARM64 и Windows Server 2025. Выполнены 30 минут синтетического аудио
через настоящий Whisper и 50 генераций протокола через Codex.
Это разные проверки, их числа не складываются в «50 сценариев Кирилла пройдены».
Живой Zoom, Windows 11 и самостоятельный запуск независимым новичком ещё
требуют проверки. MCP поддерживается на Linux/macOS; на Windows доступны скилл и CLI.

```bash
python -m unittest discover -s zoom-meeting-agent/tests -v
python zoom-meeting-agent/tools/evaluate_minutes.py --offline
```

Часть интеграционных тестов требует Chromium или Codex CLI; без них она явно пропускается. [Результаты живой оценки и границы проверки](zoom-meeting-agent/VERIFICATION.md), [изменения после аудита](CHANGELOG.md).
