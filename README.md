# AI Vibecoder Tools

Открытые инструменты для работы с ИИ. Код под MIT; установка и ограничения описаны рядом с каждым инструментом.

| Инструмент | Для чего | Запуск |
|---|---|---|
| [Zoom Meeting Agent](zoom-meeting-agent/) | Локальная расшифровка Zoom; ответы и черновик протокола через Claude по выбору | Python + браузер; Claude нужен только для ИИ-функций |
| [Zoom Meeting Agent · Codex](zoom-meeting-agent-codex/) | Та же запись и проверяемый черновик протокола через Codex | Отдельный запуск и каталог данных; Claude не нужен |

## Что происходит с данными

Zoom передаёт звук через свою сеть. Chromium сохраняет аудиофрагменты на вашем компьютере, faster-whisper распознаёт их локально. Дополнительный облачный сервис распознавания не используется.

По умолчанию LLM выключена. Флаг `--llm claude` или `--llm codex` разрешает передать текст речи и чата выбранному провайдеру. Интернет для самой Zoom-встречи нужен в любом режиме. Первый запуск также скачивает модель Whisper, если её ещё нет на компьютере.

Веб-режим только слушает; ответы в чат есть в SDK-режиме. Вход зависит от настроек встречи, авторизации и допуска организатором. Инструмент не обходит эти ограничения.

## Что проверено

В репозитории есть тесты изоляции сессий, HTTP-доступа, ошибок звука, полноты обработки текста и запуска LLM без доступа к рабочим инструментам. Отдельные 16 синтетических сценариев проверяют исполнителя, срок, проект, предложения, отмены и ошибки извлечения. Команда живой оценки модели доступна в инструкции.

Офлайн-тесты не доказывают качество ответа модели. Полученный протокол является черновиком с цитатами и требует проверки. Отмены и исправления сохраняются рядом с прежними задачами; окончательный список действующих поручений автоматически не определяется.

Разработка и локальная проверка выполнялись на Linux. Windows и macOS вручную не проверены. История «около 20 минут» относится только к первому входу прототипа в Zoom, а не ко всей настройке, доработке и проверке продукта.

## Повторить проверку

```bash
python -m unittest discover -s zoom-meeting-agent/tests -v
python zoom-meeting-agent/tools/evaluate_minutes.py --offline
```

Часть интеграционных тестов требует установленного Chromium или Codex CLI; при их отсутствии она явно пропускается. Проверка на настоящей встрече и оценка настоящей модели выполняются отдельно.
