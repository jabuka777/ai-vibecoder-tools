# Симптом → проверка → действие

Не отправляй сырые логи, .env, cookies или речь в публичный Issue. Достаточно
ОС, версий, команды без секретов, кода ошибки и обезличенного описания шага.

| Симптом | Следующее действие |
|---|---|
| Python не найден | Проверить python3/py, установить Python 3.12 с официального сайта, открыть новый терминал |
| Нет ffmpeg | Установить пакет для ОС из setup.md; снова выполнить doctor |
| Не скачиваются пакеты | Проверить доступ к указанному сервису, TLS и свободный диск; повторить setup, не отключать проверку сертификата |
| Установка оборвалась | Повторить ту же команду setup; если ошибка та же, сохранить код и этап, не запускать цикл бесконечно |
| Chromium установлен, но не запускается | doctor --check-browser; на Linux проверить системные библиотеки Playwright |
| Не найден кеш Whisper | setup --download-model, затем doctor --check-model |
| Кеш модели повреждён | setup --download-model --repair-model; затем повторить локальную загрузку модели |
| Нет окна login на сервере | Нужен доступный пользователю графический сеанс; не вводить пароль вслепую |
| login_required_run_login_py | Повторить login в видимом браузере; проверить выбранный аккаунт и политику встречи |
| Зал ожидания | Попросить организатора допустить ассистента; по таймауту честно завершить попытку |
| join_not_verified | Не считать вход успешным. Проверить экран/политику встречи, не нажимать случайные кнопки |
| audio_not_received / audio_source_lost | Проверить, что во встрече есть речь и ассистент подключён к её звуку; повторить короткую тестовую запись |
| stt_failed / stt_exited / stt_heartbeat_stale | Проверить doctor --check-model, свободную память и stt-health; сохранить полученные фрагменты |
| disk_space_low | Остановить запись и выбрать место; не удалять пользовательские записи автоматически |
| summary_failed / incomplete у протокола | Проверить вход/квоту выбранной модели; повторить только summarize после завершения записи |
| Не та версия Codex | Не обходить version gate. Проверенная 0.164.0 отдельно от основной установки, либо другой выбранный backend |
| DeepSeek authentication_required / quota_exhausted | Человек проверяет ключ/оплату в своём кабинете. Ключ в чат не запрашивать |
| DeepSeek deadline_exceeded / rate_limit | Автоповторов нет; запись сохранена. Повтор протокола после проверки соединения или лимита |
| MCP not_found / profiles пуст | Проверить home и наличие локального профиля; каталоги 0700, файлы 0600; не печатать содержимое |
| MCP secure_filesystem_unsupported | Использовать скилл и CLI; Windows MCP пока не поддерживается |
| MCP unresponsive | Не запускать дубль вслепую. Проверить свою запись/процесс и свободные ресурсы; статус записи отдельно от worker |

Не обещай ремонт смысловых ошибок настройкой окружения. WER, точность
извлечения задач и экономия времени требуют своих измерений. Код с зелёными
unit-тестами не подтверждает четырёхчасовую встречу, Windows/macOS и работу
в конкретной корпоративной сети.
