# Подготовить вход в Zoom

Для записи через Web начните с `login.py`, только если встреча требует входа
аккаунтом. Приложение в Marketplace для этого режима не нужно.

## Вход в браузере

1. После установки окружения запустите `python login.py` или обёртку
   `python skills/zoom-meeting-agent/scripts/zoom.py login` из корня репозитория.
2. Войдите в открывшемся окне доступным вашему аккаунту способом. Пароль, код
   подтверждения и CAPTCHA вводите сами в браузере. Не присылайте их ассистенту.
3. Убедитесь, что вход завершён, затем нажмите Enter в терминале. Настройки
   сохраняются в локальный `storage_state.json` с закрытыми правами.

Файл сессии даёт доступ к аккаунту: не публикуйте его и не прикладывайте к
отчётам. Сохранённый файл не подтверждает вход в конкретную встречу. SSO,
подтверждение домена, зал ожидания и разрешения организатора продолжают действовать.
Если вход истёк, повторите login. Окно браузера должно быть видно пользователю;
удалённый сервер без графического сеанса для этого шага не подходит.

Можно использовать отдельный аккаунт и имя вроде «AI-ассистент Ивана», чтобы
участники понимали, кто записывает. Создание аккаунта необязательно, если
имеющийся аккаунт подходит. Не меняйте способ входа Google/Apple/SSO только
ради инструмента. При регистрации вводите реальные данные и сами принимайте
условия сервиса. Время и доступность регистрации зависят от Zoom.

## Сохранить встречу локально

Из корня полного репозитория:

```bash
python skills/zoom-meeting-agent/scripts/zoom.py configure meeting demo --minutes 60
```

Ссылка и пароль вводятся скрыто в локальном терминале. Профиль сохраняется
в `zoom-meeting-agent/meetings/demo.json`. Запись пока не начинается.
После уведомления участников запустите:

```bash
python skills/zoom-meeting-agent/scripts/zoom.py configure run demo
```

Если используете низкоуровневый `webjoin.py` или `bot.py`, пароль передаётся
через `--password-file`. Значение в аргументе `--pwd` запрещено: его было бы
видно в списке процессов. Ссылку с параметром pwd также не вставляйте в команды.

## Meeting SDK: экспериментальный режим

По [официальному README Zoom](https://github.com/zoom/meetingsdk-web), Web Meeting
SDK предназначен для участия людей, а для ботов и AI-протоколистов Zoom указывает
RTMS. Текущий SDK-режим не является поддерживаемым Zoom решением для AI-бота.
RTMS здесь не реализован. Не начинайте с SDK ради обещания автоматических
ответов: сначала учитывайте это ограничение и требования своей встречи.

Для SDK нужны приложение и разрешения Zoom. Откройте Zoom Marketplace под
аккаунтом владельца приложения и следуйте текущей официальной инструкции
[получения credentials](https://developers.zoom.us/docs/meeting-sdk/get-credentials/).
Названия разделов Marketplace могут изменяться. Сохраните Client ID и Client
Secret через локальный запрос, без вывода в чат:

```bash
python skills/zoom-meeting-agent/scripts/zoom.py configure sdk
python skills/zoom-meeting-agent/scripts/zoom.py setup-sdk
python skills/zoom-meeting-agent/scripts/zoom.py doctor --mode sdk --check-browser --check-model --text
```

Ключи сохраняются в `.env`. Установщик SDK сохраняет предыдущий static в
`.sdk-backups`, а при ошибке возвращает его. Перед обновлением остановите
SDK-записи. Это проверка локальной установки, не доказательство совместимости
произвольной версии SDK с настоящим Zoom.

По [FAQ Zoom](https://developers.zoom.us/docs/meeting-sdk/obf-faq/), с 2 марта
2026 года для SDK-входа во встречи внешних аккаунтов требуется OBF с авторизованным
пользователем, уже присутствующим во встрече. Этот инструмент не реализует
полный OAuth/OBF-процесс. Наличие Client ID/Secret не гарантирует вход во внешнюю
встречу. Web тоже зависит от политик организатора и не гарантирует доступ по
любой ссылке.

## Проверить результат

Создайте свою короткую встречу, запустите её как организатор, допустите
ассистента и произнесите известную тестовую фразу. При необходимости включите
аудио встречи. После остановки проверьте эту фразу в transcript.md и
`recording_complete: true` в status.json. Только после такой проверки можно
говорить о работе именно на вашем компьютере и в вашей встрече.

Дополнительные симптомы и решения: [диагностика](../skills/zoom-meeting-agent/references/troubleshooting.md).
