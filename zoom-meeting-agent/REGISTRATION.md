# Регистрация: Zoom-аккаунт, приложение, профиль — все шаги

Время: около 10 минут. Всё бесплатно. Банковская карта не нужна.

Если настройку делает ваш ИИ-агент (Claude Code, Codex, Cursor), а доступа к вашей
почте у него нет, он **остановится на шаге 1.3 и попросит вас продиктовать
6-значный код** из письма Zoom. Это нормально: дальше он продолжит сам.

## 1. Отдельный Zoom-аккаунт для агента

Лучше не личный аккаунт: участники встречи видят имя и фото, а автоматике нужен вход по паролю.

1. Откройте https://zoom.us/signup.
2. Введите почту, к которой есть доступ (подойдёт отдельный ящик или алиас вида
   `you+zoom@gmail.com`), и нажмите **Continue**.
   - ⚠️ **Не нажимайте «Sign up with Google / Apple / Microsoft».** Так у аккаунта не
     будет пароля, и скрипты не смогут в него войти.
3. **Код подтверждения.** Zoom присылает письмо «XXXXXX is your Zoom verification
   code» и показывает 6 полей ввода. Код действует несколько минут; если не пришёл —
   **Resend code** и папка «Спам».
4. **Age** → выберите **18+**. Без этого форма не пустит дальше.
5. **First name / Last name** — так агента увидят во встречах, например «AI / Агент».
   **Password** — от 8 символов, с буквами разного регистра и цифрой. Сохраните его
   в менеджер паролей. → **Continue**.
6. «How will you use Zoom?» → **Skip**.
7. Готово: открылась страница `…zoom.us/myhome`.

## 2. Приложение в Zoom Marketplace (ключи для `bot.py`)

Нужно только для режима SDK — встречи вашего аккаунта. Для `webjoin.py` (любые
встречи по ссылке) этот шаг можно пропустить.

1. Под тем же аккаунтом откройте https://marketplace.zoom.us/user/build.
2. Диалог **Zoom's Marketplace Terms of Use** → **Agree**.
3. Слева рядом с «Developer» нажмите **+ (Add)** → **Build app**.
4. Второй диалог **API License and Terms of Use** → **Agree**.
5. «What kind of app are you creating» → **General app** → **Create**.
6. В меню слева: **Features → Embed** → включите переключатель **Meeting SDK**.
7. Слева: **Basic information** → блок **App credentials**: скопируйте **Client ID** и
   **Client secret** (кнопка Copy) в `.env`:
   ```
   ZOOM_SDK_CLIENT_ID=…
   ZOOM_SDK_CLIENT_SECRET=…
   ```
8. Публиковать приложение и проходить ревью Zoom **не нужно**: для встреч своего
   аккаунта хватает этих ключей.

## 3. Профиль: имя и фото, которые видят участники

https://zoom.us/profile:
- **Edit** у имени → **Display Name**: например «AI-агент Ивана» → **Save**.
- **Фото**: Zoom может сам подтянуть логотип компании по домену почты. Если не
  хотите его показывать, нажмите на аватар → **Change** → загрузите нейтральную
  картинку → **Save**.
- Если встреча уже идёт, новое имя и фото появятся только после перезахода.

## 4. Тестовая встреча (для проверки `bot.py`)

https://zoom.us/meeting/schedule:
- **Topic** — любой.
- **Show More Options** → должно стоять **Allow participants to join anytime**:
  тогда бот войдёт без вас.
- **Save**. Номер встречи (11 цифр) и **Passcode** — на странице встречи.
- Проверка: `python bot.py --mn <номер> --pwd <passcode> --minutes 2`.

## 5. Сессия для `webjoin.py` (встречи «только для залогиненных»)

Многие встречи требуют входа в Zoom («Sign in to join this meeting»). Тогда:

```bash
python login.py
```

Откроется окно браузера. Войдите аккаунтом агента: почта → **Next** → пароль →
**Sign In**. Если Zoom спросит код — он придёт на почту. Затем нажмите Enter в
терминале. Сессия сохранится в `storage_state.json`. **Не публикуйте и не
отправляйте этот файл**: в нём вход в аккаунт.

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| Бот видит экран «Sign in / Sign in Zoom / Logout» | SDK-бот в чужой встрече (ограничение Zoom с 02.03.2026) | Используйте `webjoin.py` |
| «Sign in to join this meeting» | Встреча только для залогиненных | Шаг 5 |
| Код не приходит | Письмо в спаме или опечатка в почте | Resend code, проверить спам |
| Нет поля пароля при входе | Аккаунт создан через Google/Apple | Завести аккаунт заново через почту (шаг 1.2) |
| Встреча обрывается на 40 минутах | Ограничение бесплатного тарифа Zoom | Pro-тариф или новая встреча |
