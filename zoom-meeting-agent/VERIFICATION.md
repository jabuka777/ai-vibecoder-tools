Финальный полный набор: **96 автоматических тестов, без пропусков, 23,224 с** в новом Python-окружении на Linux. В него входят настоящий Chromium с синтетическим звуком и декодированием WebM, а также установленный Codex CLI с локальным имитатором провайдера. Диагностика зависимостей прошла; авторизацию облака и вход в Zoom эта диагностика не проверяет.

Сценарии покрывают исполнителя, проект, известный и неизвестный срок, относительные сроки, предложение и принятое обязательство, отрицание, отмену, исправления и инструкцию-атаку внутри цитируемого текста. Проверяющий скрипт сопоставляет типы фактов, поля, ключевые слова и дословные основания. Допустимые варианты написания и пустые поля заданы в эталонах явно.

Проверка не устанавливает полную смысловую эквивалентность свободного текста. Другой обоснованный способ разбить разговор на факты может не пройти этот строгий формат. Протокол остаётся черновиком для проверки человеком.

## Как повторить

Команды выполняются из `zoom-meeting-agent/` в установленном окружении.

Локальные тесты и проверка эталонов:

```bash
python -m unittest discover -s tests -v
python tools/evaluate_minutes.py --offline
```

`--offline` без результатов проверяет только целостность эталонов. Для повторной проверки сохранённого живого прогона без обращения к модели:

```bash
python tools/evaluate_minutes.py --offline --results tests/fixtures/eval-luna-2026-10-26/results.jsonl
```

Проверить, что исходники и материалы совпадают с зафиксированной версией:

```bash
python - <<'PY'
import hashlib
import json
from pathlib import Path

folder = Path("tests/fixtures/eval-luna-2026-10-26")
manifest = json.loads((folder / "manifest.json").read_text(encoding="utf-8"))
for root, section in ((Path("."), "source_sha256"), (folder, "artifact_sha256")):
    for name, expected in manifest[section].items():
        actual = hashlib.sha256((root / name).read_bytes()).hexdigest()
        assert actual == expected, name
print("Source and artifact hashes match")
PY
```

Новый живой прогон требует авторизованного Codex CLI **0.164.0**, отправляет синтетические тексты модели и расходует её лимит. Каталог результата должен быть новым:

```bash
python tools/evaluate_minutes.py --backend codex --model gpt-6-luna --output-dir sessions/evaluations/luna-manual-1
```

Новый ответ модели может отличаться. Его результат нужно оценивать отдельно, не переносить на него сохранённые 16/16.

## Размер модельного контекста

В ходе доработки стандартная роль coding-агента была заменена короткой ролью текстового аналитика. Ниже, метрики одного и того же первого сценария в трёх последовательных запусках:

| Запуск | Входные токены | Из них кешированные | Выходные токены |
|---|---:|---:|---:|
| Первый, до оптимизации роли | 9 659 | 6 912 | 202 |
| Второй, после оптимизации роли | 7 177 | 3 456 | 176 |
| Финальный, после уточнения промпта | 7 381 | 3 456 | 175 |

Между первым и вторым запуском вход сократился на **25,7%**; в финальном он на **23,6%** меньше первого. Одновременно менялся промпт извлечения, поэтому это наблюдение по журналам, а не изолированный эксперимент. Более низкое число входных токенов само по себе не доказывает денежную экономию: доля кеширования изменилась, а некешированный вход первого сценария вырос с 2 747 до 3 721 токена между первыми двумя запусками. Исходные числовые данные сохранены в [сравнении метрик](tests/fixtures/eval-luna-2026-10-26/token-comparison.json).

**В этих числах есть служебный контекст CLI.** Дополнительная проверка запроса через локальный имитатор провайдера обнаружила глобальные инструкции `AGENTS.md` и каталог навыков. Флаги `--ignore-user-config`, `project_doc_max_bytes=0` и отдельный файл роли не обеспечили их отсутствия. Текст встречи вместе с этим контекстом отправляется провайдеру; на другой установке состав и размер могут отличаться. Глобальные и управляемые инструкции CLI не менялись. Проверено отключение инструментов исполнения и доступа к данным, а не изоляция запроса от всех локальных инструкций.

## Границы проверки

- Проверки выполнены на Linux. Windows и macOS вручную не проверены.
- Новая версия не проходила сквозной прогон в реальном Zoom: вход, захват звука, качество STT и отправку ответа нужно проверить отдельно на своей тестовой встрече.
- Живая модель Claude в этом прогоне не использовалась. Её параметры запуска проверяются локальными тестами с подменой процесса.
- Набор инструментов настоящего Codex CLI проверяется отдельным тестом через локальный имитатор Responses API. Такой тест не вызывает модель, не доказывает качество протокола и не обещает отсутствия глобальных инструкций в запросе.
- Синтетические тексты обходят распознавание речи: эти 16 сценариев не измеряют ошибки Whisper, шум, несколько голосов, длительные встречи, поведение на других языках и затраты человека на вычитку.
- Открытые исходники, проверенные цитаты и прошедшие тесты не означают, что протокол можно исполнять без проверки человеком.
