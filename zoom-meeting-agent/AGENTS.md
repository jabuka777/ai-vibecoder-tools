# Инструкция для ИИ-агента (Claude Code, Codex, Cursor), который настраивает Zoom Meeting Agent

Ты помогаешь человеку запустить этот инструмент. Порядок такой:

1. **Окружение** — раздел «Установка» в `README.md` под ОС человека: macOS, Windows
   или Linux. Проверь, что есть `python`, `ffmpeg`, `npm`, `claude`; чего нет —
   поставь или скажи, как поставить.
2. **Регистрация** — строго по `REGISTRATION.md`, шаг за шагом:
   - Есть доступ к почте человека (IMAP, коннектор, CLI) — возьми 6-значный код
     из письма Zoom сам.
   - **Доступа к почте нет — остановись на шаге 1.3 и попроси человека
     продиктовать код.** Не гадай и не пропускай шаг.
   - Не используй вход через Google/Apple/Microsoft: нужен аккаунт с паролем.
   - Пароль генерируй сам и сразу сохрани в `.env` или в менеджер паролей
     человека. **Не печатай пароль в чат и в логи.** Если вводишь его через
     браузерную автоматизацию, подставляй из файла, а не текстом в коде шага.
   - Client ID и Secret записывай только в `.env`, файл в `.gitignore`.
3. **Проверка без людей** — раздел «Проверка без людей» в `README.md`: два
   экземпляра бота, один «говорит» wav-файл. Готово, когда в `transcript.md`
   появилась фраза из wav, а на «бот, …» в чате пришёл ответ.
4. **Чужие встречи** — только `webjoin.py`. Перед первым входом поменяй имя и фото
   профиля (`REGISTRATION.md`, шаг 3) и спроси человека, под каким именем заходить.

Правила поведения во встречах:
- В чужую встречу — без микрофона и камеры.
- В чат чужой встречи пиши только по прямой просьбе человека, одно сообщение, без серий.
- Выжимка встречи с несколькими проектами или докладчиками делится по ним. Не
  приписывай одной команде то, что говорили о другой.
- Расшифровка и выжимка — личные данные участников: отправляй их только человеку,
  который тебя запустил.
